Simple Canvas Game

A tiny HTML/JS grid-based game. Move the green square (player) with the arrow keys and collect red squares to increase your score.

Run locally

- Open `index.html` in your browser.
- Or run a quick static server (recommended):

```bash
python -m http.server 8000
# then open http://localhost:8000
```

Files

- index.html — game page
- styles.css — simple styling
- src/main.js — game logic

Enjoy!
